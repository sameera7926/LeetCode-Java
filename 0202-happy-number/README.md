# 🔢 LeetCode 202 — Happy Number

## 📌 Problem

A number is called a **Happy Number** if we repeatedly replace the number with the **sum of the squares of its digits** and eventually reach `1`.

If the process enters a cycle and never reaches `1`, the number is **not happy**.

### Example

```text
19
↓
1² + 9² = 82
↓
8² + 2² = 68
↓
6² + 8² = 100
↓
1² + 0² + 0² = 1
```

Therefore:

```text
19 → Happy Number
```

---

## 🧠 Pattern

**Slow & Fast Pointers**

This is the same idea as **Floyd's Cycle Detection Algorithm**.

Why?

The sequence generated by a number can eventually form a cycle.

```text
Happy:

19 → 82 → 68 → 100 → 1
                         ↑
                       stops


Unhappy:

2 → 4 → 16 → 37 → 58 → 89
    ↑                   ↓
    └───────────────────┘
```

So we use:

```text
slow → moves 1 step
fast → moves 2 steps
```

If they meet:

```text
slow == fast
```

there is a cycle → number is not happy.

---

## 💡 Approach

### Step 1

Initialize both pointers with `n`.

```java
int slow = n;
int fast = n;
```

### Step 2

Move `slow` one step.

```java
slow = getNext(slow);
```

### Step 3

Move `fast` two steps.

```java
fast = getNext(getNext(fast));
```

### Step 4

If either pointer reaches `1`, the number is happy.

```java
if (fast == 1 || slow == 1) {
    return true;
}
```

### Step 5

If both pointers meet before reaching `1`, a cycle exists.

```java
if (slow == fast) {
    return false;
}
```

---

## 🔧 How `getNext()` Works

The function calculates:

> **sum of squares of all digits**

For example:

```text
n = 82

digit = 2 → 2 × 2 = 4
digit = 8 → 8 × 8 = 64

sum = 68
```

### Extract a digit

```java
int digit = n % 10;
```

`% 10` gives the last digit.

```text
82 % 10 = 2
```

### Remove the last digit

```java
n = n / 10;
```

```text
82 / 10 = 8
```

### Add square

```java
sum += digit * digit;
```

---

## 💻 Java Code

```java
class Solution {
    public boolean isHappy(int n) {

        int slow = n;
        int fast = n;

        while (true) {

            slow = getNext(slow);
            fast = getNext(getNext(fast));

            if (fast == 1 || slow == 1) {
                return true;
            }

            if (slow == fast) {
                return false;
            }
        }
    }

    public int getNext(int n) {

        int sum = 0;

        while (n > 0) {

            int digit = n % 10;
            n = n / 10;

            sum += digit * digit;
        }

        return sum;
    }
}
```

## ⚠️ Important Code Points

### `digit * digit`

```java
sum += digit * digit;
```

NOT:

```java
sum += digit + digit;
```

Because the problem asks for the **square** of each digit.

---

### Why `getNext(getNext(fast))`?

Because `fast` must move **two steps**.

```text
One step:
fast = getNext(fast)

Two steps:
fast = getNext(getNext(fast))
```

This is the same concept used in **Slow & Fast Pointer** problems.

---

## ⏱️ Complexity

Let `d` be the number of digits.

### Time

```text
O(d) per getNext()
```

The sequence reaches either `1` or a cycle after a bounded number of transformations, so for practical complexity we can state:

```text
O(log n) per digit-processing step
```

### Space

```text
O(1)
```

We don't use a `HashSet` or any extra data structure.

---

## 🎯 Interview Explanation

> "I treat the sequence of transformed numbers like a linked list and use Floyd's cycle detection. The slow pointer moves one transformation at a time, while the fast pointer moves two. If either reaches 1, the number is happy. If slow and fast meet before reaching 1, the sequence contains a cycle, so the number is not happy."
